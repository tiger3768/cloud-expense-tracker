# Cloud Expense Tracker

A backend REST API for tracking personal expenses, built with Spring Boot.

## Tech Stack

- Java 21
- Spring Boot
- Spring Security
- JWT Authentication
- Spring Data JPA
- PostgreSQL
- Docker

## Features (Phase 1)

- User Registration
- User Login
- JWT Authentication
- CRUD Operations for Expenses
- Expense Filtering
- Pagination
- Global Exception Handling
